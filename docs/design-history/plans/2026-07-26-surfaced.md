# Surfaced Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Ship the four already-plumbed capabilities per `../specs/2026-07-26-surfaced-design.md`.

**Architecture:** One contract change (action-aware read allowlist) unlocks the ledger; the other three are render work over data already fetched.

**Tech Stack:** existing only; no new deps.

## Global Constraints

- `misconception add|resolve` must be **unreachable** through `engramRead` after this change. Gate on the action argument, not the command name.
- The app never resolves a misconception; the ledger is read-only.
- Learner-model edits use the existing `modelSet`/`modelAddInterest` path — no new mutation surface, no new allowlist entries beyond the read-side action map.
- Night Atlas vocabulary; honest copy (a misconception is a recorded fact, not a failure — no danger ink for the ledger, no debt framing).
- Verification per task: `cd app && npm run typecheck && npm run build`.

### Task 1: Action-aware read allowlist + misconception IPC

**Files:**
- Modify: `app/src/main/engramCli/readOnly.ts`, `app/src/main/ipc/readHandlers.ts`, `app/src/preload/index.ts`, `app/src/shared/types.ts`

**Interfaces:**
- `readOnly.ts` gains `READ_ONLY_SUBCOMMANDS: Map<string, Set<string>>` — commands whose read-safety depends on their first argument. `misconception → {'list'}`, `experiment → {'status','list'}` (the banner in Task 3 may need it; add now, use if verified). `engramRead` consults it when `READ_ONLY_COMMANDS` misses: permitted only when `args[0]` is in that command's set. Missing action, unknown action, or unknown command → the same refusal as today. Comment must state WHY (add/resolve share the subcommand and both write).
- Produces: `Misconception { id: string; ts: string; topic: string; node: string; description: string; status: 'open' | 'resolved' }` in shared/types.ts; IPC `engram:misconceptions` → `window.engram.misconceptions()`; shape-guard the parsed rows (the file is engine-written but could be hand-edited — drop malformed entries rather than trusting).

- [ ] Implement the action map + IPC.
- [ ] **Contract test (the point of this task):** a throwaway node script exercising `engramRead('misconception', ['add', ...])`, `['resolve', ...]`, `[]`, and `['list']` against the compiled module — the first three must throw, the last must return rows. Paste the transcript into the report.
- [ ] Verify + commit `feat(engine): action-aware read allowlist; misconception list IPC`.
